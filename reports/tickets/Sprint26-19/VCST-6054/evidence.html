VCST-6054: UCP returns structured inventory errors

env vcst-qa UCP 3.1007.0-pr-9-91ca PR vc-module-ucp#9 @ 91ca741 (open) XCart 3.1037.0-pr-141-fb27 Inventory 3.1008.0 Platform 3.1073.0-pr-3121-9965 verified 2026-09-29

Before the fix, an over-stock cart mutation came back as a successful envelope. The refusal was only a message inside it, so an AI agent could tell the buyer the item was added and go on to checkout. The fix normalizes XCart's nested inventory validation errors into three stable codes, returns them as a real error (MCP isError: true, REST 409), and blocks every checkout and handoff path while the cart is invalid.

Before and after: create_cart, one unit over stock
