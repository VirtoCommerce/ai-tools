Bug and root cause

bladeNavigationService.setError read response.data.errors.join('<br>') whenever the body had no exceptionMessage or message. A bare FluentValidation list, like the one loyalty missions return, has no errors field, so the global httpError handler threw TypeError … reading 'join' and View details stayed empty. The fix extracts the message per body shape and falls back to the status text when there is none.
