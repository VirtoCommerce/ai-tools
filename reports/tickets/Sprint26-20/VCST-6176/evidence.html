VCST-6176 · Returns icon renders as legacy solid glyph

VERIFIED · 3/3

The account-menu Returns entry requested receipt-refund, which has no outline asset and no alias, so resolveIcon() fell back to the solid 20×20 glyph. PR #2544 adds the alias "receipt-refund": "undo-2" in ui-kit/utilities/icon-aliases.ts, which covers the desktop menu, the mobile menu and the Request return button.
