## Observations
- Draft rows in permalink-usages carry `canUnpublish:false`, which means nothing for a draft. If the UI reads it per row, check what it shows.
- Concurrent flagged publishes: both callers get 200 but only one page stays Published, and the other author is not told.

## Questions
- Is `POST /grouped` with a Published status meant to be supported? If yes, it needs the same check or must force Draft.
- Should publish take a lock or a concurrency token on the conflicting set?
