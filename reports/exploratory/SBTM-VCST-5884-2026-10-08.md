## Risk Areas
- The setting can be restored only to `false`, not to the original `null`: the store PUT ignores `value:null`, and my first restore left it **true** until I fixed it about a minute later.
- The Admin grid's 9th column pushes the "Item count" header under the column-menu icon ("Item cou").

## Observations
- Admin Return list: **9 columns**: Return number, Order number, Customer, **Organization**, Return status, Create date, Modify date, Created by, Item count. Clicking Organization sends `sort: organizationName:asc`; empty values sort first (screenshots/01, 02).
- Non-holder ORG_USER: `?scope=organization` falls back to My returns without a message and the URL keeps `?scope`. The Corporate area has **no Returns entry** for a holder or a non-holder, so AC-2 was built as a tab only (screenshots/03, 04).
- From a colleague's return, the "Returns" breadcrumb goes back to My returns: the org tab is lost.
- Locked account with a still-valid token: `returns`, `return`, `returnPolicy`, `returnReasons`, `createReturn`, `cancelReturn` (and `orders`) all answer `UserLocked`.
- A holder querying a foreign organization gets the uniform Forbidden. `storeId` matching ignores case.
- Console: only errors from before sign-in or from images; no errors from the returns pages.

## Questions
