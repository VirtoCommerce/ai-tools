5 tasks, 15 runs without the base and 14 with it (one excluded). Changes to the test site are counted approximately.

The totals over the five tasks. Right in every run: without the base, only one task out of five was answered correctly in all three runs; with the base, three of five. Wrong claims: four false findings without the base, one with it. Cost per right answer folds speed and accuracy into one number: 1.70 dollars without the base, 46 cents with it. All runs together took 101 minutes without the base and 28 with it. Agents without the base made about 40 changes on the shared test site while investigating; with the base about 5. And the control row: when the base holds nothing, asking it cost nothing measurable, the same 54 cents and the same accuracy. One honest note if asked: how well answers cite their sources was about the same in both setups, 97 and 93 percent, because agents without the base cite the code and API responses they found.
