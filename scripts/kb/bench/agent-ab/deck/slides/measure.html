3 runs per setup. Steps: actions the agent took (searches, API calls, file reads). Steps, cost, time: median run. Both T1 rows share the same runs without the base. *T7: both runs partly right; one run with the base excluded (search miss, then the agent stopped to wait in the background).

Each measure has two columns: grey Without is the agent without the base, orange With is the same agent with it. Correct runs: how many of three answers matched the written rubric. Wrong claims: how many runs stated something false as fact. Steps: how many actions the agent took, such as searches, API calls and file reads. Cost and time are the median run. The first T1 row is the finding: asked with one long question, the base did not find the answer it holds, and the agent guessed. The second row is the same task with the agent told to ask one short question: same accuracy as without the base, at one fifth of the cost, a seventh of the steps and a sixth of the time.
