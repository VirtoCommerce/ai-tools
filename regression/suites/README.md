# Test Suite Files Index

**Location:** `regression/suites/`
**Per-module tables:** GENERATED from the manifest by `npm run docs:index` (gated by `docs:index:check`) — a wrong suite name or priority is fixed in `config/test-suites.json`, never here.
**Format:** Enriched Agent-Native CSV (15-column)
**Manifest:** [`config/test-suites.json`](../../config/test-suites.json) — single source of truth for orchestration

Suites are organized into **module-aligned subdirectories** under `Frontend/` and `Backend/`. IDs are
zero-padded and may carry letter suffixes for split suites (e.g. `040a`, `050b1`, `072c`).

**Totals:** never transcribed here — `npm run suites:lint` prints the suite and selection counts (and
the case total in its assertion-strength line). Every CSV under `Frontend/` and `Backend/` is registered in the manifest.

## Selection Groups

Authoritative definitions live in the manifest's `selections` block. Regenerate with
`npm run suites:sync`; verify with `npm run suites:lint`. Resolve any group to its actual suite list
with `npm run regression:plan -- <name>`.

### By Priority / scope

| Selection | Suites | CI Command |
|-----------|--------|------------|
| `smoke` | 042, 078, 078b, 078c, 078d | `npm run ci:smoke` |
| `critical` | 042, 078, 078b, 078c, 078d, 039, 044, 049 | `npm run ci:critical` |
| `sprint` | `/qa-regression sprint`: plan-driven via `vc/shared/docs/Sprint plans/sprint-*-summary.json` (`--no-plan` → all P0+P1). The CI runner uses the manifest rule (all minus excludes) | — |
| `full` | All suites minus the manifest's excludes | `npm run ci:full` |

## CSV Column Format

Suites use the enriched agent-native format (15 columns):

```
ID,Title,Section,Priority,Business_Rule,Edge_Case_Refs,Preconditions,Test_Data,Steps,Assertions,Cross_Layer_Checks,Failure_Signals,Cleanup,References,Automation_Status
```

A few older Backend suites (`056`, `061`, `062`, `063`, `064`, `065`, `066`, `069`, `074`, `076`) still carry the legacy
11-column header (`ID,Title,Section,Type,Priority,Estimate,Preconditions,Steps,Expected Result,References,Automation Status`) — check a file's first line before editing it.

Authoring guides:
- Browser-mode CSV tags: [`knowledge/execution/test-runner-tags.md`](../../.claude/knowledge/execution/test-runner-tags.md)
- Runner-native GraphQL cases: [`knowledge/api/graphql-test-cases-runner.md`](../../.claude/knowledge/api/graphql-test-cases-runner.md)
