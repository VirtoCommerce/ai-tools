Bug and fix

In the customer profile Top sellers widget, a long product name squeezed the numeric columns, and the shared .vc-table__body { word-break: break-word } let them break inside the digits: Revenue $1,462.1 / 5, rank 1 / 0.

The fix adds top-sellers__number (white-space: nowrap) to the rank, units and revenue columns in top-sellers.vue. The shared VcTable rule is unchanged.
