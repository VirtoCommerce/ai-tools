VCST-6116: a refused list edit no longer persists

env vcptcore-qaPlatform 3.1076.0XCart 3.1038.0-pr-141-b404PR #141 · fix cae453d2026-10-05

Bug and root cause

addWishlistItem and updateWishListItems in PurchaseSchema.cs called Send(command), which saves the list, and only then ran AuthorizeByListIdAsync. A caller without write access got "Access denied", but the change was already stored. The fix runs the authorization before Send in both resolvers.
